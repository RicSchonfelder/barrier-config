# Barrier Config

Documentação e referências para configurar o [Barrier](https://github.com/debauchee/barrier), compartilhando teclado e mouse entre um servidor Windows e clientes macOS/Linux.

## Conteúdo

- `BARRIER-GUIA.md`: guia principal de configuração.
- `AI-REFERENCE.md`: referência compacta para consulta por agentes.
- `PROMPT-IA.md`: prompt operacional relacionado ao Barrier.
- `SKILL.md`: skill reutilizável para operações com Barrier.

## Escopo

Este repositório contém documentação e configuração. Ele não distribui o Barrier nem substitui a documentação oficial do projeto.

## Segurança

Use uma rede confiável e valide certificados/identidade dos hosts antes de compartilhar teclado ou mouse. Nunca coloque senhas, chaves privadas ou tokens nos arquivos deste repositório.
